# 📐 Analizador Pedagógico de Funciones Cuadráticas

# Resumen de la problemática a solucionar
[cite_start]La función cuadrática es una de las funciones que mas se malentiende ya que solo se enseña a través de formulas, pero nunca el que representan estas o como se obtienen, se memoriza, pero no se entiende[cite: 1].

## Objetivo general del proyecto
[cite_start]Desarrollar una herramienta computacional educativa que, entregue el análisis completo de una función cuadrática de manera clara, ordenada y pedagógica[cite: 2].

## Objetivos específicos
* [cite_start]Analizar funciones cuadráticas a partir del ingreso de sus coeficientes desde la consola[cite: 3].
* [cite_start]Aplicar los conceptos matemáticos asociados a las funciones cuadráticas para obtener información[cite: 4].
* [cite_start]Interpretar los valores de una función cuadrática con el fin de determinar el comportamiento[cite: 5].
* [cite_start]Representar de manera clara y estructurada los distintos elementos que describen una función cuadrática[cite: 6].
* [cite_start]Apoyar el aprendizaje de funciones cuadráticas mediante el uso de una herramienta computacional interactiva[cite: 6].
